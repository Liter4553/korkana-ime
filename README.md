# 한국어 발음 일본어 IME

한글 발음대로 치면 일본어로 바꿔 주는 Windows 전역 입력기. 한자 변환까지 된다.

```
하지메마시떼              ->  はじめまして
와타시하가쿠세이데스  Space ->  私は学生です
라-멘                   ->  ラーメン   (가타카나 모드)
```

`hajimemashite` 처럼 영어 발음으로 치지 않아도 된다. 윈도우 한국어 IME를
켤 필요도 없고, **영문 입력 상태에서 그냥 두벌식으로 치면** 된다.

```
타자 "gkwlapaktlEp"
  -> 두벌식 낱자 -> 하 지 메 마 시 떼 -> はじめまして -> (Space) 한자 후보
```

> ### 먼저 알아야 할 것 하나 — 조사 `は` 는 **`하`** 로 친다
>
> `は` 는 조사로 쓰일 때 **와**로 읽지만, 치는 건 소리가 아니라 **글자대로**다.
> 변환기가 읽기를 그대로 받기 때문에, 소리대로 적으면 한자 변환이 무너진다.
>
> | | 치는 것 | 결과 |
> |---|---|---|
> | ✅ | `와타시하가쿠세이데스` | 私は学生です |
> | ❌ | `와타시와가쿠세이데스` | 私羽学生です |
>
> `へ`(에로 읽음)는 **`헤`**, `を`는 **`워`**. 자세한 건
> [아래 표](#조사-は--へ--を는-글자대로-친다) 참고.

---

## 실행

**설치해서 쓰기** — [Releases](https://github.com/Liter4553/korkana-ime/releases/latest)
에서 `KorKanaIME-Setup.exe` 를 받아 실행한다.
Python 도 다른 것도 필요 없다. 관리자 권한도 필요 없다(사용자 폴더에 설치).
압축만 풀어 쓰려면 같은 곳의 `KorKanaIME-portable.zip`.

> 처음 실행하면 **"Windows의 PC 보호"** 경고가 뜬다. 코드 서명이 없고
> 키보드 훅을 거는 프로그램이라 그렇다. `추가 정보 → 실행`으로 넘어가면 된다.

**소스로 쓰기**

```bash
python ime.py
```

또는 `run.bat` 더블클릭.

**시작할 때는 꺼져 있다. `Ctrl+Alt+J`로 켜야 한다.**

### 의존성

| | |
|---|---|
| 가나 입력 | Python 3.10+ 표준 라이브러리만 (ctypes, tkinter) |
| 한자 변환 | `pip install mozcpy` (32MB, Mozc 사전) |

`mozcpy`는 **없어도 된다.** 없으면 한자 변환만 빠지고 가나 입력기로 동작한다
(Space가 변환 대신 바로 확정). 실행하면 첫 줄에 사전 상태가 찍힌다.

### 키

| 키 | 동작 |
|---|---|
| `Space` | 한자 변환 / 다음 후보 |
| `1`~`9` | 후보 번호로 바로 확정 |
| `↑` `↓` | 후보 이동 |
| `Enter` | 변환 없이 가나로 확정 |
| `Esc` | 후보창 닫기 (한 번 더 누르면 입력 취소) |
| `Backspace` | 조립 중이면 낱자 하나, 아니면 음절 하나 지우기 (후보창이 떠 있으면 닫기) |
| `-` (하이픈) | 장음 부호 `ー` |
| `Ctrl+Alt+J` | IME 켜기 / 끄기 |
| `Ctrl+Alt+K` | 히라가나 ↔ 가타카나 |
| `Ctrl+Alt+P` | 구두점 치환 켜기 / 끄기 |
| `Ctrl+Alt+Q` | 종료 |

`Space`와 `Enter`는 **미확정 입력이 있을 때만** 변환·확정에 쓰인다.
비어 있으면 평소대로 공백·줄바꿈이 들어간다. 일본어 IME와 같은 관례다.

화면 우하단에 상태 칩(`あ` / `ア` / `A`)이 뜬다. 클릭하면 켜기/끄기,
우클릭하면 종료.

### 훅 없이 변환만 해 보기

```bash
python ime.py --convert 하지메마시떼
python ime.py --convert 와타시하가쿠세이데스 --kanji
python ime.py --convert 콤퓨-타- --katakana
python ime.py --repl
```

## 입력 흐름

치는 동안에는 **아무것도 앱에 들어가지 않는다.** 확정한 것만 들어간다.
미확정창은 **치고 있는 한글**과 **변환된 가나**를 두 줄로 같이 보여준다.

```
  와타시하가쿠세이데스  을 치는 중

  메모장:  (아직 비어 있음)

  캐럿 옆 내 창:
    ┌──────────────────────────┐
    │ あ  와타시하가쿠세이데스    │   <- 지금 치고 있는 한글
    │     わたしはがくせいです    │   <- 변환된 미확정 읽기
    └──────────────────────────┘

  Space 를 누르면

    ┌──────────────────────────┐
    │ あ  와타시하가쿠세이데스    │
    │     わたしはがくせいです    │
    ├──────────────────────────┤
    │ 1  私は学生です           │  <- 선택됨
    │ 2  わたしは学生です        │
    │ 3  私は学制です           │
    │ 4  わたしはがくせいです     │
    └──────────────────────────┘

  Enter 또는 1  ->  메모장에 私は学生です
```

읽기 자체도 항상 후보에 들어간다. 한자를 원하지 않으면 그 번호를 고르거나
애초에 `Space` 없이 `Enter`를 누르면 된다.

창은 캐럿 바로 아래에 붙고, 아래 공간이 모자라면 캐럿 위로 뒤집힌다.
기준은 화면 전체가 아니라 **모니터 작업 영역**이라 작업표시줄에 가리지 않는다.

## 변환 규칙

### 초성 → 행

한국어에는 유성/무성 구분이 없어서 `ga`와 `ka`가 전부 ㄱ으로 뭉친다.
입력이 애매해지지 않게 **평음 = 탁음행, 격음·경음 = 청음행**으로 고정했다.

아래 표는 `아 / 이 / 우 / 에 / 오` 순서다.

| 초성 | 아 | 이 | 우 | 에 | 오 |
|---|---|---|---|---|---|
| ㅇ | あ | い | う | え | お |
| **ㅋ ㄲ** | か | き | く | け | こ |
| **ㄱ** | が | ぎ | ぐ | げ | ご |
| ㅅ ㅆ | さ | し | す | せ | そ |
| **ㅈ** | ざ | じ | **じゅ** | ぜ | ぞ |
| **ㅊ ㅉ** | ちゃ | ち | ちゅ | ちぇ | ちょ |
| ㄴ | な | に | ぬ | ね | の |
| ㅎ | は | ひ | ふ | へ | ほ |
| **ㅂ** | ば | び | ぶ | べ | ぼ |
| **ㅍ ㅃ** | ぱ | ぴ | ぷ | ぺ | ぽ |
| ㅁ | ま | み | む | め | も |
| ㄹ | ら | り | る | れ | ろ |
| **ㅌ ㄸ** | た | てぃ | とぅ | て | と |
| **ㄷ** | だ | でぃ | どぅ | で | ど |

즉 **평음은 탁음행, 격음과 경음은 청음행**이다.
**`카`=か / `가`=が**, **`타`=た / `다`=だ**, **`파`=ぱ / `바`=ば**, **`차`=ちゃ / `자`=ざ**.

경음(ㄲㄸㅃㅉ)은 격음과 같다. `쨩` → ちゃん, `깃떼` → きって.

> `こんにちは`는 `콘니치하`(ㅋ), `ごはん`은 `고항`(ㄱ).

### 중성 → 단

`ㅏ`→a `ㅣ`→i `ㅜ`→u `ㅡ`→u `ㅔ ㅐ`→e `ㅗ ㅓ`→o
`ㅑ`→ya `ㅠ`→yu `ㅛ ㅕ`→yo `ㅒ ㅖ`→ye
`ㅘ`→wa `ㅟ`→wi `ㅙ ㅚ ㅞ`→we `ㅝ`→wo

**`ㅜ`와 `ㅡ`는 구분된다.** 요음과 단독음을 가르는 유일한 수단이다.

| ㅜ | | ㅡ | |
|---|---|---|---|
| `주` → じゅ | `추` → ちゅ | `즈` → ず | `츠` → つ |
| `투` → とぅ | `두` → どぅ | `트` → つ | `드` → づ |

그 밖의 행은 `ㅜ`와 `ㅡ`가 같다 (`쿠`=`크`=く, `스`=`수`=す).

### 받침 → 촉음 / 발음

| 받침 | 결과 | 예 |
|---|---|---|
| ㄴ ㅁ ㅇ | `ん` | `센세이` → せんせい, `싱붕` → しんぶん |
| ㅅ ㅆ ㄱ ㄷ ㅂ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ | `っ` | `킷떼` → きって, `잇쇼` → いっしょ |
| ㄹ | `る` | `파일` → ぱいる, `메일` → めいる |

### 외래음·요음

| | | | |
|---|---|---|---|
| `샤신` → しゃしん | `쿄우` → きょう | `죠우즈` → じょうず | `뉴우스` → にゅうす |
| `화` → ふぁ | `휘` → ふぃ | `훼` → ふぇ | `훠` → ふぉ |
| `티` → てぃ | `디` → でぃ | `투` → とぅ | `두` → どぅ |

### 구두점

치환이 켜져 있으면(기본값) 일본어 구두점으로 바뀐다. `Ctrl+Alt+P` 로 끈다.

| 치는 것 | 나오는 것 |
|---|---|
| `.` | `。` |
| `,` | `、` |
| `[` `]` | `「` `」` |

Shift 를 누른 `>` `<` `{` `}` 는 건드리지 않는다. 상태는 칩의 힌트에
`구두점(。)` / `구두점(.)` 으로 표시된다.

### 장음

일본어 장음은 한글로 적을 방법이 없어서 **둘 중 하나**를 쓴다.

- 모음을 그대로 더 쓴다 — `아리가또우` → ありがとう, `쿄우` → きょう
- 하이픈 `-` → `ー` — `라-멘` → らーめん, `코-히-` → こーひー

가타카나 장음은 하이픈 쪽이 자연스럽다.

## 알아 둘 것

### 조사 `は` / `へ` / `を`는 글자대로 친다

**이게 가장 자주 걸리는 지점이다.** 한자 변환이 읽기를 그대로 받으므로,
조사를 소리대로 적으면 변환이 엉뚱하게 나온다.

| 쓰려는 것 | 치는 것 | 변환 결과 |
|---|---|---|
| `は` (와로 읽는 조사) | **`하`** | `와타시하...` → 私は学生です |
| | ~~`와`~~ | `와타시와...` → 私羽学生です ✗ |
| `へ` (에로 읽는 조사) | **`헤`** | `토우쿄우헤이쿠` → 東京へ行く |
| | ~~`에`~~ | `토우쿄우에이쿠` → 東京栄区 ✗ |
| `を` | **`워`** | `미즈워노무` → 水を飲む |
| | ~~`오`~~ | `미즈오노무` → 水尾の無 ✗ |

`오`는 항상 `お`다.

### 그 밖에

**한자 후보는 Mozc 사전이 주는 그대로다.** 문장 단위로 조사까지 처리하지만
1순위가 늘 맞지는 않는다 (`칸지헹칸` → `感じ変換`이 1순위, `漢字変換`이 2순위).
후보에서 고르면 된다. 학습 기능은 없어서 고른 걸 기억하지 않는다.

**백스페이스는 음절 단위로 지운다.** 조립 중인 음절은 한국어 IME처럼 낱자
하나씩, 이미 넘어간 음절은 통째로 지워진다. 가나 한 자씩 지우면 `쿄`(きょ)
같은 음절이 반쪽만 남아 한글 줄과 어긋나기 때문이다.

**관리자 권한으로 실행되는 창**(예: 관리자 명령 프롬프트)에서는 동작하지
않는다. 그쪽에서도 쓰려면 `ime.py`를 관리자 권한으로 실행해야 한다.

**미확정 입력은 창을 옮겨도 남아 있다.** 긴 문구를 치다 다른 창을 클릭해도
버리지 않는다. 다만 그 상태로 계속 치면 새 창에 확정되므로, 옮기기 전에
`Enter`로 확정하거나 `Esc`로 버리는 게 안전하다.

**보이는 미확정 글자와 후보창은 대상 앱 안이 아니라 캐럿 옆에 뜨는 우리
창에 있다.** TSF 기반 진짜 IME가 아니라 키보드 훅이라서 앱 안에 밑줄 글자를
넣을 수 없다.

## 구조

| 파일 | 역할 |
|---|---|
| `korkana/tables.py` | 초성→행, 중성→단, 받침→가나 매핑 |
| `korkana/kana.py` | 한글 음절 → 가나 변환 |
| `korkana/jamo.py` | 두벌식 QWERTY → 낱자 → 음절 조립 오토마타 |
| `korkana/kanji.py` | 가나 → 한자 후보 (mozcpy 래퍼, 없으면 우회) |
| `korkana/composition.py` | 미확정 입력 하나의 상태 (읽기 + 후보 선택) |
| `winime/winapi.py` | 키보드 훅 / SendInput / 캐럿 위치 (ctypes) |
| `winime/preedit.py` | 캐럿 옆 미확정창 + 후보 목록 (tkinter) |
| `ime.py` | 키 처리 상태 기계 + 진입점 |
| `applog.py` | 로그 (콘솔 없는 exe 대비) |
| `installer.py`, `make_release.py` | 설치 프로그램 / 배포 빌드 |

이어서 개발하려면 [CLAUDE.md](CLAUDE.md) 를 먼저 읽을 것. 왜 그렇게 짰는지와
이미 잡은 버그 목록이 들어 있다.

변환 엔진(`korkana`)은 Windows와 무관한 순수 Python이라 따로 쓸 수 있다.

```python
from korkana import convert, candidates
convert("하지메마시떼")                   # はじめまして
convert("라-멘", katakana=True)           # ラーメン
candidates(convert("와타시하가쿠세이데스"))  # ['私は学生です', ...]
```

## 테스트

```bash
python tests/test_kana.py
python tests/test_ime.py
python tests/test_layout.py
```

`test_kana.py`는 변환 규칙 70건. `test_ime.py`는 키 처리(버퍼링·한자 후보
선택·촉음·Shift 모음·백스페이스·핫키·키 순서 보장)를 실제 훅 없이 검증한다.
mozcpy가 없으면 한자 부분만 건너뛴다.

`test_layout.py`는 오버레이 배치를 검증한다. 가짜 캐럿을 화면 위에서 아래까지
옮기면서, 후보창이 늘 작업 영역 안에 들어오고 캐럿을 가리지 않는지 본다.
화면이 필요하므로 창이 잠깐 떴다 사라진다.
